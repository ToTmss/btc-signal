# btc-signal

Сводка по BTC и сигналы для торговли в Telegram Wallet.

- `engine.py` — индикаторы (EMA 20/50/200, ATR, объём), уровни, режим рынка, стратегии, план сделки с учётом комиссии 0,09%/сторона и дистанции до ликвидации.
- `fetch_and_summarize.py` — запускается GitHub Actions каждые 10 мин: свечи Gemini 5m/15m/1h, индекс страха и жадности, макрокалендарь → `summary.json` (~0,3–1 КБ) и бумажная торговля `paper.json`.
- `backtest.py` — проверка стратегий на истории: `python3 backtest.py data/gemini_1h.json 40`.
- `macro_calendar.json` — события США (UTC). За 15 мин до и 30 мин после события — окно без входов.

## Проверка, которую выполняет Claude (короткое задание)

1. Прочитать `summary.json` и `perps_list_positions`.
2. Если позиции нет, есть сигнал, `no_trade_window=false`, сводка свежее 20 мин — открыть ордер с entry/stop/tp из сигнала.
3. Если позиция есть — стоп в безубыток при +0,6%, иначе ничего.
4. Одна строка статуса пользователю.
